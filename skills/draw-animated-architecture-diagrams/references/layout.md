## 总览与流程

总览按实际归属逐层展开：系统/实例 → 执行上下文 → 组件 → 状态、buffer、索引或文件。共享依赖放在借用方之外。模块大小由内容和重要性决定；将内部状态画出来，避免几个等大的空框。

详细页仅保留相关组件，并可进一步展开内部数据。顺序流程优先向下推进；独立接口并排，真正的控制依赖、旁路和提前返回按需要放侧边。执行阶段分区与对象所有权用标题明确区分。

先留出布线路径，再安排卡片。尽量采用直线或少转折的正交线；对齐出入口，消除很短的装饰性折线。连接线不能靠穿过无关节点、共享线段或绕完整幅图来解决布局问题。

## 内容与语义

- 请求：输入身份、范围、数据形态及完成通知。
- 执行：关键字段、队列或 buffer 分区、索引行、范围覆盖、旧/新版本、有效/失效数据。
- 条件：判断依据、各分支终点、提前返回的输出。
- 完成：状态、实际返回对象、所有权移交与需要说明的完成条件。

按数据形态选条带、区间或小表格。卡片标题下要有有效内容；纯名称用紧凑条带。结果命名必须遵从实际 API，例如返回映射列表时，同时表现逻辑范围与映射字段。

## 配色与线型

| 角色 | 填充 | 边框 |
| --- | --- | --- |
| 请求 / 接口 | `#E5F2FC` | `#1976C5` |
| 索引 / 查询 / 完成 | `#EAF6E7` | `#3D9140` |
| 持久化 / 文件 | `#FFF1DC` | `#EF7D00` |
| 控制 / 恢复 | `#F3E6F7` | `#8635B5` |
| 中性 / 调用方 | `#F1F3F5` | `#7E8B98` |

颜色表达角色，虚实表达路径性质：正常路径为实线；条件、控制、回退和提前返回为虚线。编号仅标在每一步的一个主箭头上，标签放在对应线附近。

默认画布为 2000×1400。主内容位于 x=70..1930、y=165..1260，底部留出图例与结论；图中文字通常 17–24 px，字段值可用 14–16 px。检查原始尺寸和实际浏览宽度两种效果。改变画幅时需重排几何位置与模板边界。

每页目视检查主路径是否能顺着读、模块比例是否合理、分支归属是否明确、留白是否适量、箭头是否有必要以及光点是否影响文字。
